## Newsletter

<details>

<summary>Documentation</summary>

1. **Parse the HTML:** Load the entire source code into BeautifulSoup.
2. **Isolate the Core Content:** Target the `<main id="main-content">` tag, which contains all the newsletter articles.
3. **Identify and Extract Content Blocks:** Loop through all the content modules, which are identifiable by div tags with an id containing `hs_cos_wrapper_`.
4. **Remove Unwanted Blocks:** Specifically exclude the main header image and the legal disclaimer at the bottom.
5. **Clean and Sanitize:** For each content block that is kept, the script removes all non-essential HTML attributes (like class, style, data-hs-cos-type, etc.) from every tag. This leaves only the basic structural elements (`<p>, <img>, <a>`) and their necessary attributes (`href, src`).
6. **Rebuild a Clean HTML:** The cleaned content is then placed into a new, simple HTML document with minimal styling for readability.

Here is the complete Python script that will perform the cleaning. You can save this as a  `.py` file to reuse for future newsletters.

<summary>Python Script</summary>

```python
# clean_html.py
# This script reads a bloated HTML file, cleans it, and writes the result to a new file.

from bs4 import BeautifulSoup

# --- Configuration ---
# You can change these filenames if you like.
INPUT_FILENAME = 'newsletter.html'
OUTPUT_FILENAME = 'cleaned_newsletter.html'
# -------------------

def clean_newsletter_html(html_content: str) -> str:
    """
    Cleans the HubSpot-generated HTML to extract only the newsletter content.

    Args:
        html_content: The raw HTML string of the newsletter.

    Returns:
        A string containing the cleaned and simplified HTML.
    """
    # 1. Parse the original HTML using a robust parser.
    soup = BeautifulSoup(html_content, 'lxml')

    # 2. Create a new, clean HTML structure for the output.
    new_soup = BeautifulSoup("""
    <html>
      <head>
        <meta charset="utf-8">
        <title>Retail News & Views - Cleaned</title>
        <style>
          body { font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif; line-height: 1.6; max-width: 800px; margin: 20px auto; padding: 0 20px; color: #333; }
          img { max-width: 100%; height: auto; border-radius: 4px; display: block; }
          .section-header { margin-top: 2.5em; margin-bottom: 1.5em; border-bottom: 2px solid #eee; padding-bottom: 1em; }
          .article { border-bottom: 1px solid #eee; padding-bottom: 1.5em; margin-bottom: 1.5em; }
          .article p { text-align: justify; margin: 0; }
          .article img { max-width: 120px; margin-right: 15px; float: left; }
          a { color: #0056b3; text-decoration: none; font-weight: bold; }
          a:hover { text-decoration: underline; }
          h1, h6 { text-align: center; }
          h6 { color: #555; font-weight: normal; }
        </style>
      </head>
      <body>
      </body>
    </html>
    """, 'lxml')
    
    body_tag = new_soup.body

    # 3. Extract the title and date and add them to the new document.
    original_title = soup.find('title')
    if original_title:
        title_tag = new_soup.new_tag('h1')
        title_tag.string = original_title.get_text(strip=True)
        body_tag.append(title_tag)
    
    date_tag = soup.find('div', id='hs_cos_wrapper_widget_1685354285961')
    if date_tag:
         body_tag.append(date_tag.find('h6'))


    # 4. Find the main content area.
    main_content = soup.find('main', id='main-content')
    if not main_content:
        body_tag.append(new_soup.new_tag('p').string = "Error: Could not find the main content area.")
        return new_soup.prettify()

    # 5. Find all content blocks and clean them up.
    content_blocks = main_content.find_all('div', id=lambda x: x and 'hs_cos_wrapper' in x)
    
    # List of block IDs to completely remove (e.g., banner, footer disclaimer).
    EXCLUDE_IDS = [
        'hs_cos_wrapper_widget_1748266530226',
        'hs_cos_wrapper_widget_1685354285961',
        'hs_cos_wrapper_widget_1751469570284',
        'hs_cos_wrapper_module_16861473992953'
    ]

    for block in content_blocks:
        if block.get('id') in EXCLUDE_IDS:
            continue

        # Clean attributes from all tags inside the block, keeping only essential ones.
        for tag in block.find_all(True):
            allowed_attrs = {'src', 'href', 'alt', 'title'}
            attrs_to_remove = [attr for attr in tag.attrs if attr not in allowed_attrs]
            for attr in attrs_to_remove:
                del tag[attr]

        # Add classes for styling based on content.
        # This makes the final output much nicer.
        if block.find('img', alt=lambda x: x and 'Header' in x):
            # This is a section header image
            block.attrs['class'] = 'section-header'
        elif block.find('p'):
            # This is an article paragraph
             block.attrs['class'] = 'article'

        body_tag.append(block)

    return new_soup.prettify()


if __name__ == "__main__":
    try:
        with open(INPUT_FILENAME, 'r', encoding='utf-8') as f:
            raw_html = f.read()
        
        print(f"Successfully read '{INPUT_FILENAME}'. Cleaning...")
        
        cleaned_html = clean_newsletter_html(raw_html)
        
        with open(OUTPUT_FILENAME, 'w', encoding='utf-8') as f:
            f.write(cleaned_html)
            
        print(f"Success! Cleaned HTML has been saved to '{OUTPUT_FILENAME}'.")

    except FileNotFoundError:
        print(f"Error: Input file not found. Please make sure a file named '{INPUT_FILENAME}' exists in the same directory as the script.")
    except Exception as e:
        print(f"An unexpected error occurred: {e}")
```
